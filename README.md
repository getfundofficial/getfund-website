# GETFund Public Website

Official website for Ghana Education Trust Fund.

## Tech Stack
- React 18
- Vite 7
- TypeScript
- Tailwind CSS
- React Router

## Development

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```
- Runs on **http://localhost:5173**

### Build for Production
```bash
npm run build
```

## Environment Variables

Create a `.env` file (already created):
```env
VITE_CMS_API_URL=http://localhost:5000/api
```

## Related Projects

- **CMS Backend**: `../getfund-cms/backend`
- **CMS Frontend**: `../getfund-cms/frontend`

## Content Management

All content is managed through the CMS at http://localhost:5174
